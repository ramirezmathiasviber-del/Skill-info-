### An HTML-native skill format for AI

A `skill.info` file is a wrapped `index.html` built to hold visual knowledge an AI can search and use.

![HTML](https://img.shields.io/badge/HTML-native-7C4DFF?style=flat-square&logo=html5&logoColor=white)

<sub>text　·　code　·　UI　·　images　·　charts　·　references</sub>

</div>

---

## ☾ Why

AI skills are usually long text files. That works for instructions, but visual knowledge needs more.

**Skill Info makes the skill a webpage.** Rules, code, screenshots, charts, layouts and references can live together.

<div align="center">

![Rule](https://img.shields.io/badge/rule-Keep%20the%20main%20action%20easy%20to%20scan-2B174D?style=for-the-badge)
![Reference](https://img.shields.io/badge/reference-dashboard.png-7147C9?style=for-the-badge)
![Tags](https://img.shields.io/badge/tags-dashboard%20%7C%20hierarchy%20%7C%20spacing-9B7AE5?style=for-the-badge)

</div>

The AI gets both the instruction and the visual reference behind it.
