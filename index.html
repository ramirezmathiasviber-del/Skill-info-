UI Design Skill

This file is both documentation and structured knowledge. A person can open it in a browser. An AI loader can parse the HTML, search tags, read rules, inspect examples, and discover images or chart data without loading everything at once.

How AI should read this file

  1. Parse the HTML instead of treating it as one giant text block.
  2. Find elements marked data-skill-entry.
  3. Search data-tags, headings, and text for the current task.
  4. Read only the best matching entries.
  5. Collect linked images, examples, chart data, and rules from those entries.
  6. Return the selected knowledge to the AI as context.

Primary button

Use one clear primary action in an area. Avoid multiple buttons fighting for attention.

<button class="primary">Continue</button>

Dashboard layout

Keep navigation stable. Put the page title near the top. Group related controls. Use spacing before adding borders.

Images and visual references

Images can live inside the repo or use a URL. The loader reads the image path, alt text, caption, and nearby rules. Replace the example path with real references as the skill grows.

Chart knowledge

Use bars for category comparisons and lines for ordered trends. Keep labels readable and remove decoration that does not help understanding.

The JSON is machine-readable. The HTML is human-readable.

Entry format

<section data-skill-entry data-type="layout" data-tags="dashboard spacing">
  <h2>Dashboard</h2>
  <p data-rule>Rule the AI should learn.</p>
  <img src="assets/reference.png" alt="Useful description">
</section>

Add as many entries as needed. Large libraries can split knowledge into more HTML files and let the loader fetch them only when needed.
